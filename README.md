Object-oriented analysis and design of an online appointment system for an ophthalmology clinic, documented in the repository wiki.

## About

Course project for Systems Development I at Universidade Presbiteriana Mackenzie
(2023, second semester). A clinic wants to replace manual scheduling with a website
where visitors browse the available exams and, after logging in, book appointments,
review their schedule, update their profile, pay and rate the service. The team
modeled the system step by step, from the demand definition to the design class
diagram. The documentation is in Portuguese.

The same scenario was later implemented as a Django web app in
[ProjetoPegaVisao](https://github.com/EnzoFerroni/ProjetoPegaVisao).
